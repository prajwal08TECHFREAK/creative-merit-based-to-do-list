# Little List for Greater Things

A retro-inspired, client-side to-do app built with vanilla HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Deploy with GitHub Pages

1. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
2. In the repository, open **Settings → Pages**.
3. Select the deployment branch and the `/ (root)` folder, then save.

Tasks, points, photos, and preferences are stored in the browser's local storage on the device where the app is used.
